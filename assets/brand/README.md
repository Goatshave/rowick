# Rowick brand assets

The active-cell symbol uses three charcoal cells and one apricot selected cell.
The selected cell moves above its outlined position.

- `logo.svg`: horizontal enamel logo for light backgrounds.
- `logo-dark.svg`: horizontal enamel logo for dark backgrounds.
- `symbol.svg`: enamel symbol with a transparent background.
- `symbol-mono.svg` and `symbol-inverse.svg`: solid-color symbols.

The base colors are charcoal `#4B4946`, apricot `#E4AF86`, warm stone `#8C877E`,
and ivory `#F4F1E9`. Highlights are part of the enamel finish.
Keep the selected-cell offset, empty outline, and clear space around the symbol.

The examples use a simplified favicon at
[`examples/shared-assets/favicon.svg`](../../examples/shared-assets/favicon.svg).
It adapts to light and dark browser tabs. The ICO versions use a middle gray
for readability in either theme.

The wordmark is outlined from Instrument Sans, with a rounded dot over the i.
The font's [SIL Open Font License](Instrument-Sans-OFL.txt) is included.
These assets do not require the font to be installed.
