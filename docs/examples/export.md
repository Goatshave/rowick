# CSV export

Export filtered rows across every local page.

<ClientOnly><FeatureDemo key="export" feature="export" /></ClientOnly>

## Try it

Choose **Design** and click **Download CSV**. The file contains three matching
rows, including Emma Wilson on the next page. **Preview CSV** shows the same text before downloading, in every framework.

The output is generated by Rowick’s export API; the button only creates a browser
download from that text.

## Implementation

Open **Code**, choose **React**, **Vue** or **Svelte**, then select a file
from the file explorer. Start with `src/App.tsx`, `src/App.vue` or
`src/App.svelte`. Data, columns and styles live in separate files.

The framework selector switches both the live preview and its source files.
Each preview is built from the files shown in the code viewer. Install the
selected framework, its matching `@rowick/*-ui` package, and `@rowick/core`.
Svelte source targets Svelte 5. The included styles reproduce the preview’s grid theme.
See the [shared setup](setup.md) for framework integration details.

## Behavior and boundaries

`rowScope: "filtered"` includes all filtered rows, not just the visible page.
For a page-only export use `"page"`; for selected loaded rows use `"selected"`.
When no rows match, download is disabled. The CSV preview explains the empty result.
Client export cannot include unloaded server rows. Use a server export job for
complete remote results, and a typed XLSX schema for spreadsheet files.

Read the [analytics export guide](../analytics-export.md) for the full contract.
